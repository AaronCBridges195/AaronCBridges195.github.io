Solar Sector Financial Dashboard

Tracking how solar companies respond financially to federal policy
Python SQL SQLite Streamlit SEC EDGAR API

An interactive dashboard analyzing how solar energy companies' financial performance responds to federal policy changes, built from live SEC filings and market data.

  • Built a Python ETL pipeline ingesting SEC EDGAR filings and market data for 9 renewable energy companies, resolving inconsistent financial reporting tags across companies and filing-standard transitions
  • Designed a normalized SQLite database and wrote SQL queries using window functions, CTEs, and multi-table joins to calculate revenue growth, margins, and stock returns around policy events
  • Implemented incremental data fetching, automated logging, and error handling for unattended daily refreshes via Windows Task Scheduler
  • Built an interactive Streamlit dashboard with dynamic filtering and layered visualizations comparing company performance against events like the Inflation Reduction Act
